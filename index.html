Systems · Distributed Storage

LDS — Linux Distributed Storage

C++20 · Linux · NBD · epoll · TCP/IP · Multithreading · Reactor Pattern · RAID01

Distributed block-storage system designed to expose remote storage through a Linux block-device interface. The project combines Linux systems programming, networking, concurrency and extensible software architecture.

  • Built an event-driven server around an epoll-based Reactor architecture for handling NBD and TCP communication.
  • Implemented asynchronous request dispatching through a multithreaded worker pool while keeping the Reactor event loop non-blocking.
  • Designed a unified request path for READ, WRITE, FLUSH and TRIM operations.
  • Implemented a pluggable storage architecture supporting multiple storage backends.
  • Added RAID01-style storage distribution with striping and mirrored redundancy across storage nodes.
  • Applied modular C++ design using interfaces, factories, command dispatching and runtime-loadable components.

School Timetable Optimizer

Python · ILP · PuLP · CBC / GLPK · Flask · HTML / CSS / JavaScript

Optimization system that automatically generates school timetables by translating real scheduling requirements into an Integer Linear Programming model.

  • Defined an optimization objective and constraints for teacher availability, workload, subject requirements, schedule conflicts and days off.
  • Implemented the optimization model with PuLP using CBC / GLPK solvers.
  • Added validation of input requirements before invoking the optimization stage.
  • Integrated the solver with a Flask web application that accepts JSON scheduling data and presents generated timetable views.
