Flagship Project · Distributed Systems

LDS — Linux Distributed Storage

C++20 · Linux · NBD · epoll · TCP/IP · Multithreading · Reactor Pattern · RAID01

Distributed block-storage system built in C++20, exposing remote storage through Linux NBD and TCP interfaces under a unified event-driven architecture.

  • Built an epoll-based Reactor for event-driven NBD and TCP communication.
  • Implemented asynchronous request dispatching through a multithreaded worker pool while keeping the Reactor event loop non-blocking.
  • Designed a unified request path for READ, WRITE, FLUSH and TRIM operations across multiple communication transports.
  • Designed a pluggable storage layer supporting interchangeable storage backends.
  • Implemented RAID01-style storage distribution combining striping and mirrored redundancy across storage nodes.
  • Applied modular C++ architecture using interfaces, command dispatching, factories and runtime-loadable components.

School Timetable Optimizer — Integer Linear Programming

Python · ILP · PuLP · CBC / GLPK · Flask · HTML / CSS / JavaScript

Built a constraint-based scheduling engine that models school timetabling as an Integer Linear Programming problem and solves it using optimization solvers.

  • Modeled teacher, subject, class, day and time-slot assignments using binary ILP decision variables.
  • Defined optimization objectives and constraints covering teacher availability, workloads, subject requirements, schedule conflicts, days off and timetable preferences.
  • Implemented the optimization engine in Python using PuLP with CBC / GLPK solvers.
  • Added input validation to identify inconsistent or infeasible scheduling requirements before invoking the solver.
  • Integrated the optimization engine with a Flask web application for supplying scheduling data and visualizing generated timetables.
